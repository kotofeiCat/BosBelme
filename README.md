# BosBelme (RoomBox OS) 🚀

**BosBelme** (или **RoomBox OS**) — это современная мультиплеерная веб-платформа для совместных игр и real-time взаимодействия. Проект построен по принципу комнат (румов), где пользователи могут собираться вместе и играть в динамичные мини-игры в реальном времени.

Внутри платформы уже реализована встроенная 2D-мультиплеерная игра **One-Shot Bounce** с кастомным физическим движком.

---

## ✨ Основные фичи

*   **Управление комнатами:** Быстрое создание игровых сессий, генерация уникальных комнат и управление состоянием игроков.
*   **Real-time синхронизация:** Мгновенный обмен данными между игроками без задержек.
*   **Встроенные игры:** Физический 2D-движок для аркады *One-Shot Bounce*.
*   **Ready for Production:** Полная контейнеризация приложения, автоматический CI/CD пайплайн и встроенный мониторинг метрик.

---

## 🛠 Технологический стек

Проект развернут на самом свежем и производительном стеке:

*   **Backend:** .NET 10 (ASP.NET Core)
*   **Real-time коммуникация:** SignalR
*   **База данных:** PostgreSQL
*   **Контейнеризация:** Docker & Docker Compose
*   **Мониторинг:** Prometheus & Grafana
*   **CI/CD:** GitHub Actions

## 📂 Структура проекта

Архитектура платформы разделена на изолированные слои (Clean Architecture / Многослойная архитектура), что упрощает масштабирование и добавление новых мини-игр.

```text
├── .github/
│   └── workflows/              # Конфигурация CI/CD автоматизации (GitHub Actions)
│
├── BosBelme/                   # Презентационный слой (Веб-приложение ASP.NET Core)
│   ├── Config/                 # Конфигурационные файлы и инициализация приложения
│   ├── Controllers/            # Контроллеры управления страницами и API эндпоинтами
│   ├── Properties/             # Системные настройки проекта (launchSettings.json)
│   ├── ViewModels/             # Модели данных для отображения во Views
│   ├── Views/                  # Интерфейс комнат и страниц (Razor Views)
│   │   ├── Account/            # Страницы авторизации и профилей
│   │   ├── Games/              # Игровые экраны
│   │   ├── Home/               # Главная страница платформы
│   │   └── Hub/                # Интерфейс лобби и игровых комнат
│   └── wwwroot/                # Статический фронтенд-контент
│       ├── css/                # Стили страниц и кастомные темы
│       ├── img/                # Графические ассеты и иконки
│       ├── js/                 # Клиентские скрипты управления игрой
│       └── lib/                # Внешние библиотеки (Bootstrap, jQuery, Validation)
│
├── BosBelme.Data/              # Слой работы с базой данных (Data Access Layer)
│   ├── Entities/               # Доменные модели базы данных PostgreSQL (Игроки, Комнаты)
│   └── Migrations/             # История миграций Entity Framework Core
│
├── BosBelme.Service/           # Слой бизнес-логики и real-time коммуникаций
│   ├── Config/                 # Специфичные настройки бизнес-логики
│   ├── Dto/                    # Объекты передачи данных (Data Transfer Objects)
│   ├── Extension/              # Методы расширения (Extensions) для сервисов
│   ├── IService/               # Интерфейсы (контракты) бизнес-сервисов
│   ├── Service/                # Реализация бизнес-логики приложения
│   └── SignalR/                # Real-time хабы (SignalR Hubs) для мгновенного обмена данными
│
└── One_Shot_Bounce/            # Изолированный игровой модуль
    ├── Engine/                 # Кастомный 2D физический движок (коллизии, траектории)
    └── Models/                 # Внутриигровые модели объектов (мяч, ракетки, препятствия)
```
