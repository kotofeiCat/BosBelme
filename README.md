# RoomBox 🎮

**RoomBox** — это современная мультиплеерная веб-платформа для совместных игр в реальном времени. Проект построен по принципу комнат, где пользователи могут собираться вместе и играть во множество мини-игр в реальном времени.

Внутри платформы уже реализована встроенная 2D-мультиплеерная игра **Tank a catch**.

---

## 🗝️ Ключевые возможности

*   **Управление комнатами:** Быстрое создание игровых комнат, для игры с друзьями.
*   **Real-time синхронизация:** Мгновенный обмен данными между игроками без задержек.
*   **Встроенные игры:**: *Tank a catch*.
*   **Ready for Production:** Полная контейнеризация приложения, автоматический CI/CD пайплайн и встроенный мониторинг метрик.

---

## 🛠 Технологический стек

Проект развернут на самом свежем и производительном стеке:

*   **Backend:** .NET 10 (ASP.NET Core)
*   **Real-time коммуникация:** SignalR
*   **База данных:** PostgreSQL
*   **Контейнеризация:** Docker & Docker Compose
*   **Мониторинг:** Prometheus & Grafana
*   **CI/CD:** GitHub Actions

## 📂 Структура проекта

Архитектура платформы разделена на изолированные слои (Clean Architecture / Многослойная архитектура), что упрощает масштабирование и добавление новых мини-игр.

```text
├── .github/
│   └── workflows/              # Конфигурация CI/CD автоматизации
│
├── BosBelme/                   # Презентационный слой
│   ├── Config/                 # Конфигурационные файлы
│   ├── Controllers/            # Контроллеры управления страницами и API эндпоинтами
│   ├── Properties/             # Системные настройки проекта 
│   ├── ViewModels/             # Модели данных для отображения во Views
│   ├── Views/                  # Интерфейс комнат и страниц 
│   │   ├── Account/            # Страницы авторизации и профилей
│   │   ├── Games/              # Игровые экраны
│   │   ├── Home/               # Главная страница платформы
│   │   └── Hub/                # Интерфейс лобби и игровых комнат
│   └── wwwroot/                # Статический фронтенд-контент
│       ├── css/                # Стили страниц и кастомные темы
│       ├── img/                # Графические ассеты и иконки
│       ├── js/                 # Клиентские скрипты управления игрой
│       └── lib/                # Внешние библиотеки
│
├── BosBelme.Data/              # Слой работы с базой данных
│   ├── Entities/               # Доменные модели базы данных PostgreSQL
│   └── Migrations/             # История миграций Entity Framework Core
│
├── BosBelme.Service/           # Слой бизнес-логики и real-time коммуникаций
│   ├── Config/                 # Специфичные настройки бизнес-логики
│   ├── Dto/                    # Объекты передачи данных 
│   ├── Extension/              # Методы расширения для сервисов
│   ├── IService/               # Интерфейсы бизнес-сервисов
│   ├── Service/                # Реализация бизнес-логики приложения
│   └── SignalR/                # SignalR Hubs для мгновенного обмена данными
│
└── One_Shot_Bounce/            # Изолированный игровой модуль
    ├── Engine/                 # Логика игрового поведения
    └── Models/                 # Внутриигровые модели объектов 
```
